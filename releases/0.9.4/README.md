# LS Connect v0.9.4 – Static Preview Hotfix

Diese Version ersetzt den fehleranfälligen lokalen Proxy-Preview-Startweg.

- `/api/script` wird clientseitig sicher auf die bestehende Production geroutet.
- Relative Basis-Ressourcen werden gegen die Production aufgelöst.
- Der Windows-Starter fällt sauber von Python auf PowerShell zurück.
- Fehler bleiben sichtbar; die BAT schließt nicht mehr kommentarlos.
- Stable, Production-Loader, Supabase, Auth, LMH, PCAD und Banking bleiben unverändert.
